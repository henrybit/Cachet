# Cachet — 产品功能与特点说明

## 一句话介绍

**Cachet** 是一款面向开发者与运维的轻量级桌面应用，用于统一管理 **Redis** 与 **Memcached** 中的缓存数据：连接、浏览、读写、过期与排查，一站完成。

## 产品定位

| 维度 | 说明 |
|------|------|
| 目标用户 | 后端 / 全栈开发者、SRE、需要频繁查看缓存内容的业务同学 |
| 使用场景 | 本地联调、预发验证、线上只读排查、批量查看键与 TTL |
| 产品形态 | 原生桌面应用（Tauri），跨 macOS / Windows / Linux |
| 核心价值 | 双引擎一体、界面清晰、操作路径短、凭证本地安全存放 |

## 核心功能

### 1. 双引擎缓存管理

- 同时支持 **Redis** 与 **Memcached**
- 按引擎自动适配默认端口、能力差异与交互提示
- 同一应用内维护多条连接，按需切换，无需来回换工具

### 2. 连接生命周期管理

- 新建 / 编辑 / 删除连接配置
- 一键 **测试连接**，保存前即可确认可达性
- 连接参数覆盖主机、端口、用户名、密码、数据库、TLS、超时等
- 连接列表支持检索，快速定位目标环境

### 3. 键空间浏览与检索

- 支持模式扫描（如 `user:*`、`cache:*`），快速缩小键范围
- Redis 侧基于 SCAN，适合生产环境安全遍历
- 列表分页 / 游标加载，避免一次拉全量导致卡顿
- 支持按精确键名 **直接读取**，跳过扫描直达目标

### 4. 键值读写与编辑

- 查看键名、值、类型、大小与 TTL
- 新建键值并写入
- 原地编辑已有值并保存
- 删除无用或错误键
- Memcached 以字符串形态清晰展示，降低心智负担

### 5. TTL 与过期管理

- 查看键剩余生存时间（永久 / 即将过期 / 可读时长）
- 写入或更新时可设置 TTL（秒）
- 便于排查「为什么缓存没了」与「为什么还在」

### 6. Redis 多数据库切换

- 支持在 DB 0–15 间切换
- 切换后自动刷新当前键列表，减少手动重扫

### 7. 服务端信息查看

- 在工作区内查看当前连接对应的服务信息摘要
- 辅助确认版本、状态与基础运行指标（依引擎能力展示）

### 8. 本地安全与持久化

- 连接配置本地持久化，重启后仍在
- **密码写入系统钥匙串（Keychain / Credential Store）**，不落明文配置文件
- 适合在个人开发机长期保存常用环境，同时降低凭证泄露面

## 产品特点

### 轻量，不臃肿

基于 Tauri + 系统 WebView，安装包小、启动快，聚焦「管缓存」本身，而不是堆砌无关能力。

### 双引擎统一体验

Redis 与 Memcached 共用同一套连接侧边栏与工作区布局，学习成本低；引擎差异在细节上给出明确提示，而不是强迫用户记两套工具。

### 面向日常排障的操作流

左侧选连接 → 上方扫键 / 读键 → 下方看详情并改值。路径短、反馈直接，适合联调与线上排查的高频节奏。

### 安全默认

密码走系统钥匙串；桌面端本地运行，数据请求直连你的缓存实例，不经第三方中转。

### 跨平台一致

同一套产品能力覆盖 macOS、Windows、Linux，团队成员可使用同一工具约定操作习惯。

## 界面结构

```
┌─────────────┬──────────────────────────────────────┐
│  连接列表    │  扫描 / 读取工具栏                      │
│  （侧边栏）  │  键列表                                │
│             ├──────────────────────────────────────┤
│  + 新建连接  │  键值编辑器 / 服务信息                   │
└─────────────┴──────────────────────────────────────┘
```

- **左侧**：全部连接入口，品牌与引擎一目了然
- **右上**：键空间导航（扫描、读取、DB 切换）
- **右下**：当前键的详情与编辑区

## 适用与不适用

| 适合 | 不太适合（当前版本） |
|------|----------------------|
| 日常查看 / 修改单个或小批量键 | 大规模数据迁移、全库导出导入 |
| 多环境连接切换与联调 | 集群拓扑可视化、复杂运维编排 |
| Redis + Memcached 混用团队 | 仅需命令行脚本自动化的纯 CI 场景 |
| 注重本地凭证安全的个人开发机 | 需要多人协同审计的企业级权限体系 |

## 快捷操作（摘要）

| 功能 | 快捷键（macOS） |
|------|-----------------|
| 新建连接 | `Cmd + N` |
| 新建键 | `Cmd + K` |
| 保存 | `Cmd + S` |
| 删除 | `Delete` |
| 刷新 | `Cmd + R` |

## 技术概要

| 层级 | 技术 |
|------|------|
| 桌面壳 | Tauri 2 |

| 原生能力 | Rust（Redis / Memcached 协议访问、钥匙串） |

## 版本与路线图提示

当前版本聚焦：**连接管理、键浏览、读写、TTL、双引擎统一体验**。

后续可演进方向（非承诺）：更多 Redis 数据类型可视化、只读模式、连接分组 / 颜色标记、导入导出连接配置、更新器等。
